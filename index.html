安装指引

三步完成安装

1

下载 APK

点击上方"下载 Android 版"按钮，将 APK 文件保存到手机。

2

允许安装

在文件管理器中点击 APK，若提示"未知来源"，前往设置允许安装。

3

开始使用

安装完成后在桌面找到"每日打卡"图标，打开即可使用。

卸载方法：长按桌面图标拖至"卸载"，或在设置 → 应用管理中卸载。卸载后数据自动清除。
1

下载安装包

点击上方"下载 Windows 版"按钮，保存 DailyCheck-Setup.exe 到任意目录。安装包已内置 Java 运行环境，无需额外安装 Java。

2

运行安装包

双击 DailyCheck-Setup.exe，在弹出的确认框中点击"是"，程序会自动解压到本地并启动。

3

开始使用

应用启动后即可使用。后续可从解压目录 %LOCALAPPDATA%\DailyCheck\DailyCheck.exe 直接启动。

卸载方法：删除解压目录 %LOCALAPPDATA%\DailyCheck\ 即可。数据存储在 %APPDATA%\dailycheck\，删除该目录可清空数据。
