安装与启程

整合包采用 PCL2 可识别的 MultiMC 格式。导入后由启动器安装 Minecraft 与 Forge。

01 — PREPARE

启动前准备

  1. 使用支持导入整合包的 PCL2 启动器。
  2. 安装并选择 Java 17（Java 21 也可）。
  3. 为游戏分配 8–10 GB 内存；不建议超过 12 GB。
02 — INSTALL

导入并启动

  1. 将整合包 ZIP 拖入 PCL2 主窗口，或在「版本设置 → 安装整合包」中选择。
  2. 确认创建「匠造与奥术 1.20.1」实例。
  3. 首次启动会生成模组配置，加载约 3–6 分钟属于正常情况。
