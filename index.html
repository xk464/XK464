FIRST STEPS

新手教程：从下载到第一天

整合包采用 PCL2 可识别的 MultiMC 格式。模组和配置已经打包好，导入后启动器会安装游戏本体与 Forge。

01

准备环境

准备支持导入整合包的 PCL2。选择 Java 17（Java 21 也可），给游戏分配 8192–10240 MB 内存。

02

导入 ZIP

把下载的 ZIP 拖到 PCL2 主窗口，或在「版本设置 → 安装整合包」中选择文件，确认实例名后导入。

03

首次启动（会「无响应」，别关它）

第一次启动要注册 239 个模组、生成配置并重载资源包。这段时间窗口标题会变成「无响应」，画面可能整个卡住 —— 这是正常的，不是崩溃。请等待 1～3 分钟，不要点「结束程序」、也不要反复强制关闭，否则可能损坏配置文件。想看它有没有在动，可以打开启动器的日志窗口。

04

创建新世界

建议先创建新世界体验预设配置。进入游戏按 L 打开进度界面，从「安家落户」开始做任务。

⚠ 关于「无响应」：本整合包有 239 个模组，启动时和第一次进入世界时窗口会短暂显示「无响应」，这是模组注册、配方与数据包加载、出生点区块生成占满了主线程导致的，属于正常现象。请耐心等待 1～3 分钟，不要强制关闭。第二次进入同一个世界会明显变快（包里已装 Fastload / Noisium / Async Locator）。
运行配置：Minecraft 1.20.1 / Forge 47.4.10 / Java 17 优先 / 内存建议 8–10 GB。8 GB 以下更容易在模组加载时遇到内存不足；分配超过 12 GB 也未必更流畅。

开局先做什么？

先收集木材、石材和基础食物，按 - 查看任务提示；制作农夫乐事的刀与灶台，尽早准备更好的食物。之后做背包和储物抽屉安置物资，再放床、设置家并探索周边。

怎样查配方和方块信息？

打开物品栏或 JEI 列表，鼠标悬停物品后按 R 查看配方、按 U 查看用途。对准方块时 Jade 会显示名称和额外信息；按 M / B 查看小地图 / 世界地图。

矿脉、树木与作物

按住潜行键（默认 Shift）挖矿石可触发连锁挖矿；用斧头砍树干可整树伐倒；对成熟作物右键收获并补种。连锁挖矿默认最多连锁 32 个方块，留意工具耐久。

回家与联机传送

使用 /sethome 名称 设置家，/home 名称 回家，/homes 列出家；/back 返回死亡点或上次传送前的位置。联机可用 /tpa 玩家 请求传送，对方用 /tpay 接受、/tpan 拒绝。权限取决于服务器设置。

关于「再进世界很慢」：进入世界时的等待主要来自三块：JEI 重建配方索引、数据包加载、出生点区块生成。
另外，v1.5.0 之前包里带过 I18nUpdateMod，它会在游戏最早期加载阶段联网检查汉化包更新（请求 raw.githubusercontent.com 和 GitHub Releases）—— 在访问 GitHub 不畅的网络下会卡住或反复重试，正好卡在启动最早期，是「无响应」的主要来源。v1.6.1 已移除它，汉化改由包内静态资源包提供。

原版进世界时会一次性预生成出生点周围 21×21 = 441 个区块，全部生成完才把控制权交给你 —— 这才是「创建完退出、再进要等很久」的主因。包里已经装了 Fastload（只先加载 1 个区块）、Noisium（世界生成热路径优化）和 Async Locator（结构定位不再卡主线程）。想彻底解决探索卡顿，建好世界后跑一次 /chunky radius 1000 再 /chunky start 预生成。

小提示：大规模探索前可了解包内 Chunky 区块预生成模组，并查看游戏内命令帮助。低配显卡先关闭光影或选择 MakeUp - Ultra Fast；Complementary Reimagined 画质更丰富。降低模拟距离通常比单纯降低视距更能改善卡顿。
MOD GUIDE

模组介绍：先认识这些伙伴

整合包包含 246 个模组。下面按玩法介绍代表性模组；部分模组需要先制作对应物品或阅读游戏内指南。

联机Boss 挑战科技工业魔法冒险生活建造操作与体验性能与画面

01 · 联机：把世界开放给朋友

e4mc · 一键联机

像平时一样「对局域网开放」，聊天栏会额外给出一个公共域名。把域名发给朋友，他在「多人游戏 → 直接连接」里粘贴就能进来。朋友不需要装 e4mc，也不用端口映射或公网 IP，只有开世界的人需要装。

Simple Voice Chat · 语音

带距离衰减的近距离语音，模组界的语音事实标准。同一局域网或自建服务器开箱即用；通过 e4mc 联机时语音走独立的 UDP 24454 通道，需要在主机上做额外端口映射。

Packet Fixer · 大包防护

239 个模组下，背包、AE2 网络、机械动力装置的数据包可能超出原版大小上限，服务器会直接把玩家踢下线。这个模组把上限放宽。

02 · Boss 挑战：休闲之外的硬仗

Mutant Monsters · 变异怪物

僵尸、苦力怕、骷髅、末影人的变异体，会分裂、会召唤、会把人扔出去 —— 经典的「挑战目标」，也是第七章的起手四连。

Bosses'Rise · 魂系 Boss

带来冥界骑士赫尔瓦、炼狱飞龙阿什洛德、巨型沙虫斯洛克与霜冻雪怪斯科尔，战斗节奏接近魂类游戏：节奏、走位和容错都很关键。

Progressive Bosses · 原版 Boss 强化

每击杀一次末影龙或凋灵，它们下次都会更强。让原版终局内容有了重复挑战的意义，也让第七章的最后两战名副其实。

Gateways to Eternity · 永恒之门

基于波次的战斗事件：放下一道门，怪物一波波涌出，清完拿奖励。适合当刷装备、测试 build 或和朋友一起打的场地。

已有的 Boss 内容也串进来了

灾变（末影守卫、焰魔、利维坦）、Mowzie's Mobs（钢铁守护者、霜冻巨兽）、Alex's Caves（暝煌龙）、深海迷航（船长科妮莉亚）、铁魔法与法术书（死者之王）—— 第七章用 16 个任务把它们排成了一条升级路线。

03 · 科技工业：亲手搭建自动化

Create · 机械动力

以转轴、齿轮和传动带构建可见的机械系统。适合做物品搬运、加工产线和富有创造性的工厂，是推荐的科技起点。

Mekanism · 通用机械

发展电力、机器与矿石处理链，适合中后期提高资源利用率。先从基础机器和供电开始，再逐步扩展处理流程。

Applied Energistics 2 · AE2

搭建数字化物品存储与自动合成网络。初学者可先理解频道、存储与供电，再循序扩展自动合成。

Immersive Engineering · 沉浸工程

以大型多方块机器和工业风设备丰富生产线，适合喜欢实体工厂与沉浸式建造的玩家。

Thermal 系列 · 热力科技

提供机器、能源和资源处理等科技内容，可作为 Create 与大型工业线之间的补充选择。

Sophisticated Storage · 精致存储

提供升级型存储容器，帮助整理大量材料；搭配背包和储物抽屉，逐步建立清晰的仓储区。

04 · 魔法与冒险：另一种成长方式

Ars Nouveau · 新生魔艺

收集魔源、学习法术并组合施法效果，还能探索自动施法。想玩魔法，可以从法术书和基础法术开始。

Botania · 植物魔法

围绕植物、花朵与魔力展开的魔法模组，可把资源生产、装置和自动化结合起来。

Blood Magic · 血魔法

以仪式和生命资源为主题的进阶魔法路线。建议先熟悉基础生存，再按指南逐步学习。

Blue Skies · 蔚蓝天空

开启新的维度冒险与探索路线；准备好装备、食物和地图，再踏上远行。注意：本整合包包含蔚蓝天空，不包含 The Aether 天境。

Apotheosis · 神化

扩展附魔、装备词缀与战利品成长，让探索和战斗获得更多装备构筑空间。

YUNG's Better 系列

翻新多种原版结构与地下地点，让熟悉的世界生成更多值得探索的空间。

05 · 田园与建造：把基地变成家

Farmer's Delight · 农夫乐事

加入烹饪、厨房器具和丰富食物。初期制作刀具与灶台，准备多样食物支持长途冒险。

Waystones · 传送石碑

发现或建造传送点，减少基地与已探索地点之间的往返时间。

Macaw's 系列

补充家具、门窗、桥梁等建筑部件，让基地、农庄和工厂更有自己的风格。

Storage Drawers · 储物抽屉

适合按物品类型收纳大量常用材料；将抽屉集中摆放，能快速看清库存。

我们的生物群系 / 静谧四季

探索 Oh The Biomes We've Gone 带来的群系与自然景观，感受 Serene Seasons 的季节变化。

Supplementaries / Quark

扩展方块、装饰和实用细节，给日常建造与生存流程增加更多选择。

06 · 操作便利：让信息和整理更顺手

JEI · 物品与配方查询

打开物品栏后搜索物品；按 R 看配方、按 U 看用途。找不到合成路线时，先从 JEI 查起。

Jade · 方块信息

将准星对准方块或生物，查看名称及额外信息。遇到陌生机器时先看提示，再打开对应指南。

Inventory Profiles Next

在背包与容器界面使用整理功能，支持排序和锁格等操作。不要把重要物品误放进丢弃位置。

Vein Mining · 连锁挖矿

默认按住潜行挖矿触发，未附魔时可连锁最多 32 个方块；留意工具耐久与掉落物容量。

Tree Harvester / RightClickHarvest

用斧头伐树、右键采收成熟作物，减少重复操作。采集前确认背包有足够空间。

Xaero's Minimap / World Map

使用 M 打开小地图、B 打开世界地图，标记基地和重要地点，降低探索迷路的概率。

Simple Warp TPA Home Back

提供 home、back、warp 与玩家传送相关命令。多人服务器上具体权限由服务器规则决定。

IMBlocker / Controlling

IMBlocker 改善 Windows 输入法与游戏按键冲突；Controlling 可搜索按键绑定，方便排查快捷键冲突。

Keep Inventory Always

整合包预设新世界死亡保留物品。想恢复死亡掉落规则，可在当前世界使用 /gamerule keepInventory false。

07 · 性能与画面：按机器情况选择

Embeddium + Oculus

分别提供渲染优化与光影支持。若遇到画面异常或帧率低，先关闭光影排查。

ModernFix / FerriteCore

改善加载、内存占用等方面的体验；大型模组包首次启动仍需要耐心等待。

Chunky / Entity Culling

Chunky 可用于区块预生成；Entity Culling 减少不可见实体的渲染负担。

MakeUp - Ultra Fast

偏向较低配置的光影选择。核显或帧率有限时，可先尝试它或直接关闭光影。

Complementary Reimagined

画面效果更丰富，性能压力也更高。确认基础游玩流畅后再开启。

崩溃助手 / Crash Assistant

发生崩溃时协助查看问题信息。记录错误提示与日志，有助于定位加载器、内存或模组问题。

为什么换成任务书原版进度界面是一张自动布局的大图，任务一多就没法看。Heracles 是手工排版的树状任务书，位置由我逐个数着摆，主线支线一眼分明。
蓝图是奖励「蓝图与建造」这条线的奖励就是建造魔杖本身：石 → 铁 → 钻石 → 无限，外加天使/破坏/魔杖三种核心，以及 Create 的蓝图台与蓝图加农炮。
命令快捷页任务书左侧还有一个 commands 页，9 个可重复点击的命令按钮（设置家 / 回家 / 家列表 / 返回 / 公共传送点…），点完成再领奖就会执行，不用手打命令。
任务是怎样判定的？唯一页签的入口会随玩家首次进入世界自动授予，所以按 L 之后立刻能看到全部 139 个任务；内部按「支线」分成 12 条并排的路线，每条支线各走各的前置关系。代码中的物品类目标由 inventory_changed 条件检查指定物品（部分要求 8、16 或 64 个）；维度目标在跨入下界/末地时触发；Boss 目标通过玩家击杀事件触发。每个任务连接单独的奖励函数，完成后直接执行 give / xp 指令发奖励。
奖励说明：奖励会在完成瞬间自动发放，包含物品或经验；例如铁器时代会奖励后续冒险所需物资，击败末影龙的任务也准备了阶段性奖励。若不确定下一步，打开任务描述查看提示。

出发前记住这些

快捷键可能与其他模组或玩家设置冲突；可在选项的按键设置中搜索模组名称并自行调整。

怎么和朋友一起玩？

进入世界后按 ESC 点「对局域网开放」，聊天栏会给出一个 xxxx.e4mc.link 形式的公共域名。朋友在「多人游戏 → 直接连接」里粘贴即可，他不需要装 e4mc。主机退出世界后域名立即失效，下次开世界会换一个新的。

常用按键速查（完整版见 键位总表）

- 任务书；R/U 查询配方/用途；Ctrl+O 切换 JEI 列表；Ctrl+F 搜索按键；Z 缩放；M/B 地图；K 饰品栏；Tab Jade 信息。

命令不用记，任务书里点一下就行

任务书左侧有一个「commands」页，里面是 9 个可重复点击的命令按钮：设置家、回家、家的列表、返回上一位置、公共传送点等。点「完成」再点领奖，命令就执行了，不用手打。

老版本升级建议

若曾导入过旧版，建议在 PCL2 删除旧的「匠造与奥术 1.20.1」实例，再导入 v1.10.0 ZIP。重要存档先备份；不要在旧实例里混装另一加载器的模组。

仍然崩溃怎么办？

先确认 Java 17、内存分配和 Forge 版本；关闭光影后再启动，并查看崩溃助手或日志中的首个错误。不要同时升级多个模组，以免难以定位问题。
